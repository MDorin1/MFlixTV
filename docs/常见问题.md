# 常见问题

## 启动与安装

**Q：双击图标没反应 / 窗口一闪而过**
A：确认安装目录下 `runtime\node.exe`、`app\.next`、`hongguo\server\src\main.js` 都在。
命令行进安装目录执行 `lihongguotv.exe` 可看到具体报错；日志在 `logs\web.log`。

**Q：浏览器打开是空白 / 502**
A：主站没起来。看 `logs\web.log`。常见原因是端口 8080 被占：
`netstat -ano | findstr :8080` 找到后结束进程，或改用别的端口。

**Q：Windows 提示「未知发布者」**
A：没有代码签名。点「更多信息 → 仍要运行」。杀软把 `node.exe` 误报同理，加信任即可。

**Q：macOS 提示「已损坏，无法打开」**
A：未公证 + 隔离属性。执行 `xattr -dr com.apple.quarantine ./lihongguotv-macOS`，或右键 → 打开。

## 播放

**Q：某些片源点开黑屏 / 一直转圈**
A：多半是那个采集站的 CDN 挂了或不给流。换一个来源（搜索卡片上「N 源」展开），或用 `tools\bench-sources.ps1` 测速后调整源列表。

**Q：红果某一集播不出来**
A：先换一集试试；仍失败就在播放器错误提示里点 720p/540p 降档重试（会重新拉流）。
确认不是网络问题后，可用托盘的「检查更新」升级红果内核。

**Q：红果首播要等十几秒**
A：正常。单集需要「下载密文 → 解密 → 转 H.264」，命中缓存后同一集秒开。

**Q：拖动进度条卡**
A：看具体源。红果是服务端解密的 mp4，支持 Range，拖动一般没问题；主站的 HLS 取决于源站分片响应速度。

## 数据

**Q：换电脑 / 换浏览器，历史没了**
A：红果历史会同步到服务端 `.data\history.json`（同一台机器/同一个局域网内的设备共享）。
主站的播放进度存在浏览器 IndexedDB，不跨设备。

**Q：想清空历史**
A：红果页「清空历史」按钮（会同时清服务端）；单条删除是卡片右上角的 ×。

**Q：改密码**
A：编辑 `app\.env` 的 `PASSWORD=`，重启应用。

## 更新

**Q：点「检查更新」后播放中断了**
A：更新点播源后如果生效，会重启一次主站（约 2 秒）。所以建议不在看片时点。

**Q：红果突然全空 / 搜不到任何东西**
A：上游改了签名或接口。等 [hongguo-web](https://github.com/sunnysky123/hongguo-web) 更新后，再点「检查更新」。
如果长期不恢复，说明那条逆向路线当前不可用，不是你的配置问题。

**Q：一个源都搜不出来**
A：把 `logs\update.log` 发到 issue。通常是公开源列表也失效了，需要在 `tools\update.ps1` 的 `$REMOTE_LISTS` 里补新列表地址。

## 开发

**Q：`npm install` 很慢**
A：换镜像 `npm config set registry https://registry.npmmirror.com`。

**Q：改了 `hongguo/` 之外的东西要不要重新打包**
A：改 `app/src` 需要 `npm run build` 再重启；改 `tools/update.ps1`、`packaging/*` 不影响运行时，但发布安装包要重新编译。
