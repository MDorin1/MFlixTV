# 端识别：同一个地址，按访问方给合适的界面

MFlixTV 只有一个服务端，界面有几套：手机版（`index.html`，竖屏卡片、手指点）、电视版（`tv.html`，10 英尺大卡片、方向键走）。以前只能靠用户记地址（`/` 手机版、`/tv` 电视版）——没人会记，所以电脑和电视浏览器打开局域网地址，看到的都是那个窄手机界面。

## 判定顺序

1. **地址栏显式指定**：`?ui=tv` / `?ui=m`。同时写 cookie `mfl_ui`（30 天），下次这台设备直接用这版。
2. **上次的选择**：cookie `mfl_ui=tv|m`。
3. **UA 推断**（`WebServer.guessScreen`）：
   - 含 `leanback / android tv / googletv / smart-tv / hbbtv / bravia / aft* / fire tv / shield / mibox / appletv / web0s / netcast / tizen / crkey / chromecast / hisense / skyworth / changhong / tv box` → **电视**
   - 含 `iphone / ipad / ipod` 或 `mobile` 或 `android`（且不含上面那些电视标志）→ **手机**
   - 其余（`Windows NT` / `Macintosh` / `X11` / `CrOS`）→ **电脑**
4. 拿不准的一律当**电脑**：手机上误判还能用（页面还是响应的），电视上误判就是「点不到」。

界面映射：手机 → `index.html`；电视、电脑 → `tv.html`（大卡片在电脑上也好看，方向键/鼠标都能用）。

## 手机不认「电视版」cookie（硬规则）

手机上拿到的界面固定是手机版，**除非地址里显式写 `?ui=tv`**（只当次有效）。cookie 里记着 `mfl_ui=tv` 也不理。

起因：在手机上误点过一次「电视版」，cookie 记 30 天，之后这台手机打开就是电视界面——播放条按钮小、点不到，全屏也不会进 iOS 的播放内核。手机版的「全屏」才有 `webkitEnterFullscreen` 那条路（回到苹果自己的播放界面）。

电脑不受这条限制：`?ui=m` 选过手机版，cookie 照样记住。

## 电脑上打开电视版时的缩放

电视版字号基准 = 视口宽 /96，3440 宽显示器上会放大成 36px，播放条会压住字幕、右上角按钮被挤出屏幕。电脑命中 `html.desk` 后字号上限 22px、播放控件按 px 收一遍（播放键 44px、按钮 36px、播放条限宽 1080px）。电视 / 盒子 / 手机不命中 `html.desk`，原样不动。

## 手动切换入口

| 界面 | 位置 | 去向 |
| --- | --- | --- |
| 电视版 | 顶栏「手机版」按钮（`#btnPhone`） | `/?ui=m` |
| 手机版 | 设置 → 「界面」卡 → 电视版（`#sUiTv`） | `/?ui=tv` |

想回到自动判断：清掉该站点的 Cookie。

## App 自己也要说清楚

安卓 App 的 WebView 打开时**显式带上** `?ui=`：电视模式 `/tv?ui=tv`、手机模式 `/?ui=m`。原因是有些盒子的 WebView 报的是普通 Android UA，靠 UA 猜会猜成手机版——遥控器方向键就成了「点不到」。

## 验证脚本

`D:\Build\ua-test.ps1`（UA 矩阵）与 `D:\Build\ua-test2.ps1`（cookie 优先级）。要点：

- Windows / macOS / Shield TV / BRAVIA 的 UA 打 `/` → 电视版（响应体含 `id="navItems"`）
- iPhone / Android 手机 UA → 手机版（含 `id="setBtn"`）
- 电脑 UA + `?ui=m` → 手机版，且响应头带 `Set-Cookie: mfl_ui=m`
- 带 `mfl_ui=m` 的电脑 UA 再打 `/` → 仍是手机版
- cookie 是乱值 → 回退 UA 判断

> 注意：PowerShell 5.1 的 `-Headers @{'Cookie'=...}` 会丢掉 Cookie（受限头），要测 Cookie 优先级用 `curl.exe -H "Cookie: ..."`，否则会误判成「cookie 没生效」。

## 没做的一处（有意）

电脑版服务（Next）没有搬到 `tv.html`：它缺 `/api/home`、`/api/lines`、`/api/list.m3u`、`/api/sources/health`、`/api/sources/toggle` 这五个接口，硬塞会让电视页白屏。电脑版本身就是桌面界面，电视建议用盒子/手机上的 MFlixTV。
