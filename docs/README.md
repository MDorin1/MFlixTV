## 几条贯穿全项目的约束

写在这里是为了每次改代码前先看一遍，别踩着老坑：

1. **取流链路是红线**：`hls` 配置、预取器、分片缓存、`/api/proxy` 一行都不许改。所有优化的前提是起播速度与预加载能力只能持平或更好。
2. **短剧只动短剧那一条链**：吐流改造（边解密边发流、Range 映射）限死在短剧内核与短剧播放页。
3. **对外只有一个名字**：`MFlixTV`（大小写固定），短剧专区里的旧字样也早已换成「MFlixTV短剧」。
4. **GitHub 上的公开文字不留具体片名、演员名**；截图里出现也要打码，但不能影响整体观感。
5. **中文文件一律用编辑器写**：`index.html` / `tv.html` / `rc.html` / `*.kt` / `*.md` 不要用 PowerShell 的 `Set-Content`（会写 BOM + CRLF，还会吃中文）。
