# 随包许可文本 / Bundled Licenses

本目录收集**随安装包一起分发**的第三方二进制与源码所使用的许可文本，以及获取对应源码的方式。

| 文件 | 对应组件 | 许可 |
| --- | --- | --- |
| [`../LICENSE`](../LICENSE) | 本项目（含上游 LibreTv 代码） | AGPL-3.0 |
| [`MIT-hongguo-web.txt`](MIT-hongguo-web.txt) | hongguo-web（安装包内含运行时源码） | MIT |
| [`Node.js.txt`](Node.js.txt) | Node.js 运行时 | MIT（含其第三方声明） |
| [`FFmpeg.txt`](FFmpeg.txt) | FFmpeg 静态构建 | LGPL-2.1-or-later / GPL-3.0 |
| [`Apache-2.0.txt`](Apache-2.0.txt) | hls.js、mpegts.js、mux.js、dexie | Apache-2.0 |

## 如何获取对应源码

| 组件 | 源码 |
| --- | --- |
| 本项目 | 本仓库（含全部修改） |
| LibreTV 上游 | https://github.com/LibreSpark/LibreTV |
| hongguo-web | https://github.com/sunnysky123/hongguo-web |
| Node.js | https://nodejs.org/en/download/ （对应版本源码 tarball） |
| FFmpeg | https://ffmpeg.org/download.html 、https://github.com/BtbN/FFmpeg-Builds |

如需其他形式（例如书面要约），请通过仓库 Issue 联系。
