当前代理未设置
「源站测速」会并发打一遍所有源，按耗时排序，慢的沉到后面；一个都不通时会自动去远端把源清单拉回来。「重新获取片源」是手动触发同一件事。
代理填手机上梯子的 HTTP 端口（v2ray / Clash 都可）。留空表示直连；改完会重新取一次片单。
后台常驻 息屏 / 切后台后别的设备还要能连
电池优化白名单检查中…
息屏常驻（CPU 不休眠）检查中…
手机锁屏后网卡能连、CPU 却被系统挂起时，别的设备来拉分片就没人应答——表现是「一开始能播，手机一锁屏就卡住」。息屏常驻会一直持着 CPU 唤醒锁（不亮屏，只醒着），最稳；嫌耗电可以切省电模式：只在有播放流量时醒着。国产 ROM（MIUI / ColorOS / EMUI / 鸿蒙）还要在系统设置里给 MFlixTV 打开「自启动」和「后台允许运行」。
